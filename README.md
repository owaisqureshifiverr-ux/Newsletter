# The Monthly Pulse — Employee Edition

This repository hosts the static, employee-facing edition of **The Monthly Pulse** for Code Informatics.

## What's included
- `index.html` — the employee-facing static newsletter page.
- `.nojekyll` — instructs GitHub Pages to serve the static site without Jekyll processing.
- `.github/workflows/pages.yml` — GitHub Actions workflow for deploying to GitHub Pages.

## First-time publishing
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Open the **Actions** tab and run **Deploy The Monthly Pulse to GitHub Pages** if the workflow does not start automatically.
4. The employee URL will be `https://owaisqureshifiverr-ux.github.io/Newsletter/`.

## Important content and privacy notes
- The employee edition does not include the HR workspace, login dialog, editing controls, upload controls, or HR demo password.
- The current November 2026 issue is a clean editorial starter because the supplied Word template contained section prompts but no completed monthly stories. Verified and approved updates must be added before treating this as a completed newsletter.
- The GitHub repository is public. The page is therefore publicly accessible, not protected by an employee sign-in. Publish only content approved for public web access; do not add confidential company or employee information.
