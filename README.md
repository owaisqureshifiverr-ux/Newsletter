# The Monthly Pulse — Employee Edition

This repository hosts the static, employee-facing edition of **The Monthly Pulse** for Code Informatics.

- Public entry point: `index.html`
- The employee edition does not contain the HR workspace, login dialog, edit controls, upload controls, or HR demo password.
- Only publish content approved for public web access. This repository is public, so the site is not access-restricted to employees.
- The current November 2026 issue is an editorial starter shell because the supplied Word template contained section prompts but no completed monthly stories. Add verified, approved stories before treating it as a completed issue.

The site is deployed to GitHub Pages by the workflow in `.github/workflows/pages.yml` once Pages is enabled for the repository.
